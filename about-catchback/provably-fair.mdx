## Real-Time Optimization Algorithm

Our system continuously monitors live market values and automatically sorts cards into value buckets (P0-P5). The system uses **[machine learning optimization](https://docs.scipy.org/doc/scipy/reference/optimize.html)** to ensure pack probabilities automatically adapt to market conditions while guaranteeing you never pay more than expected value.

A pull's card is chosen in these steps:

1. **Seed.** The first 8 hex digits of the pull's id are read as an integer.
2. **Draws.** A Linear Congruential Generator started from the seed produces the draws, one per step: `state = (0x41C64E6D × state + 0x6073) mod 2^32`.
3. **Bucket.** One draw picks the value bucket, using the bucket odds.
4. **Shuffle.** For a bucket of `n` cards, `n − 1` more draws shuffle its cards.
5. **Card.** The next draw picks a place in the shuffled list.
6. **Result hash.** A SHA-256 hash of the seed, bucket, place and card id is recorded with the pull.

The current algorithm is named `shuffle-scaled-v3`. The full steps, with code you can run, are in [Verify a pull](/partner-api/verify-a-pull).

## Card Pulling Process

### How Individual Cards Are Selected

Once our optimization system has calculated the fair probabilities for each value bucket, the actual card selection process begins. When you open a pack, CatchBack generates the pull's id, a UUID, and the first 8 hex digits of it, read as a number, are the seed. The seed feeds a Linear Congruential Generator (LCG): `state = (0x41C64E6D × state + 0x6073) mod 2^32`. Given the same seed, the same draws always follow, so a pull can be replayed and checked.

### Permanent Audit Trail

Every pull is recorded with its seed, selected card, timestamp and a result hash. You can check any pull by taking the id we provide, running it through the algorithm above and confirming you got the card you should have received, or by using [Verify a pull](/partner-api/verify-a-pull). You can check that your result follows from its seed and that the record hasn't changed. CatchBack generates the seed when the pull is made.
