---
title: "Create a shipment"
api: "POST /api/partner/v1/shipments"
description: "Ship cards you hold to a customer's address, charged to your balance at the carrier's full rate."
---

Scope: `ship:cards`, granted on request · MCP tool: `create_shipment`, which takes the header below as `order_id`

Charges your balance the rate's full amount and queues the shipment for us to fulfill. We quote again before charging: if the rate has gone above `max_cost`, nothing is charged and you get `409 PRICE_CHANGED`. Read [Shipping cards](/partner-api/shipping) first, including what covers a parcel.

<ParamField header="Idempotency-Key" type="string" required>
  Your id for this shipment, 8–128 characters of `A-Za-z0-9_-`, unique per account among your shipments. Pack and card order ids are a separate set. Reuse it to retry the same shipment safely: [Retries](#retries).
</ParamField>
<ParamField body="card_ids" type="string[]" required>
  1–10 card ids from [Get vault](/partner-api/endpoints/get-vault), each once. A listed card has to be [delisted](/partner-api/endpoints/delist-card) first.
</ParamField>
<ParamField body="address" type="object" required>
  Your customer's address, with the same fields and limits as [Estimate a shipment](/partner-api/endpoints/estimate-shipment).
  <Expandable title="address">
    <ParamField body="name" type="string" required />
    <ParamField body="address1" type="string" required />
    <ParamField body="address2" type="string" />
    <ParamField body="city" type="string" required />
    <ParamField body="state" type="string" />
    <ParamField body="zip" type="string" />
    <ParamField body="country" type="string" required />
    <ParamField body="phone" type="string">Required outside the US.</ParamField>
  </Expandable>
</ParamField>
<ParamField body="rate" type="object" required>
  The rate you chose from [Estimate a shipment](/partner-api/endpoints/estimate-shipment).
  <Expandable title="rate">
    <ParamField body="carrier" type="string" required>e.g. `USPS`.</ParamField>
    <ParamField body="token" type="string" required>e.g. `usps_priority`.</ParamField>
  </Expandable>
</ParamField>
<ParamField body="max_cost" type="number" required>
  The most you'll pay for this rate, in dollars: more than 0 and at most 10,000. Normally the `amount` from the estimate.
</ParamField>

## Response

`200`, with the shipment and every field described in [List shipments](/partner-api/endpoints/list-shipments). A new one is `processing`.

<ResponseField name="idempotent_replay" type="boolean">Present and `true` when this answers a retry of a shipment that went through. The body is the shipment as it stands now, which may have moved on.</ResponseField>

## Errors

| Status | Code | When |
|---|---|---|
| `400` | | A missing or malformed `Idempotency-Key`, a body that isn't JSON, `card_ids` that aren't 1–10 card ids (or list one twice), an invalid address (`"error": "Invalid address"` with `fields`, which names each bad field and never repeats its value), a `rate` that isn't a carrier and token, or a missing or out-of-range `max_cost` |
| `400` | `INSUFFICIENT_BALANCE` | Your balance is below the rate. The body has the `amount`. Nothing was charged |
| `400` | `COUNTRY_NOT_SUPPORTED` | We don't ship to this country |
| `400` | `OVER_CUSTOMS_CAP` | An international shipment worth over $2,500, or with a card we have no value for |
| `400` | `PARTNER_GOODS` | A partner's own goods ship from that partner |
| `403` | | The key lacks `ship:cards` or isn't linked to an account, the account needs a verified phone number (`"Phone verification required"`), the account is deleted (`"Partner account unavailable"`), or it can't request shipping |
| `403` | `FEATURE_RESTRICTED` | The account is restricted from the marketplace or from withdrawals (`capability` is `marketplace` or `withdraw`). Contact us |
| `409` | `CARDS_NOT_SHIPPABLE` | A card can't ship. `cards[]` gives each refused `card_id` and its `reason`: [what they mean](/partner-api/shipping#which-cards-can-ship). A card lost at the last moment comes with no `cards` list: read [Get vault](/partner-api/endpoints/get-vault) again |
| `409` | `RATE_UNAVAILABLE` | The carrier no longer offers that rate. Estimate again |
| `409` | `PRICE_CHANGED` | The fresh rate is above `max_cost`. The body has `amount` and `max_cost`. Nothing was charged |
| `409` | `IDEMPOTENCY_IN_PROGRESS` | A shipment with this id is still running, or is with our team (`needs_review: true`). The body has `shipment_id` and `started_at`. Follow it with [Get a shipment](/partner-api/endpoints/get-shipment) |
| `409` | `IDEMPOTENCY_RETRY` | An earlier attempt with this id just failed, and freed the id. Resend the same id |
| `422` | `IDEMPOTENCY_KEY_REUSED` | This id was already used for a different shipment |
| `429` | `DAILY_SHIPMENT_LIMIT_REACHED` | This key has made 50 shipments today (UTC). The body has `limit` and `resets_at` |
| `500` | | The shipment didn't go through and nothing was charged. Try again with the same id |
| `500` | `SHIPMENT_OUTCOME_UNKNOWN` | We couldn't confirm whether the charge went through. It's with our team (`needs_review: true`, with its `shipment_id`). A retry with the same id never charges again, and never resend it under a new id until you hear from us: [what to do](/partner-api/shipping#unconfirmed-shipments) |
| `502` | | We couldn't confirm the carrier rate, and nothing was charged. Try again |
| `503` | | We couldn't check the account, the cards or your daily limit, or start the shipment, and this attempt charged nothing. Try again with the same id |

A refused shipment charges nothing and frees its id, so you can fix the problem and send it again under the same id.

## Retries

| You send an id that… | You get | Charged? |
|---|---|---|
| Is new | The shipment runs | Once |
| Belongs to a shipment that went through | The shipment as it stands now, plus `"idempotent_replay": true` | No, not again |
| Belongs to a shipment still running | `409 IDEMPOTENCY_IN_PROGRESS`, with `shipment_id` and `started_at` | No, not again |
| Belongs to a shipment with our team | `409 IDEMPOTENCY_IN_PROGRESS` with `needs_review: true`, until we've checked it. If it did go through, you get the shipment instead | No, not again |
| Belongs to an attempt that just failed, or was cut off before it reached the charge | `409 IDEMPOTENCY_RETRY`. Resend it | No |
| Belongs to an attempt we refused | The shipment runs again | Once, if it succeeds this time |
| Was used for a different shipment | `422 IDEMPOTENCY_KEY_REUSED`. Use a new id | No |

If a shipment still answers `409` after 30 minutes, contact us with its `shipment_id`.

<RequestExample>
```bash cURL
curl -X POST https://catchbackcards.com/api/partner/v1/shipments \
  -H "Authorization: Bearer $CATCHBACK_KEY" \
  -H "Idempotency-Key: ship-2077" \
  -H "Content-Type: application/json" \
  -d '{
    "card_ids": ["0e94dc61-5a2f-4b1e-9c3d-7f8a1b2c3d4e"],
    "address": {
      "name": "Sam Rivera",
      "address1": "1 Example Way",
      "city": "Testville",
      "state": "CA",
      "zip": "94000",
      "country": "US"
    },
    "rate": { "carrier": "USPS", "token": "usps_priority" },
    "max_cost": 12.85
  }'
```
</RequestExample>
