---
title: "List withdrawals"
api: "GET /api/partner/v1/withdrawals"
description: "Your latest USDC withdrawals, newest first."
---

Scope: `withdraw:funds`, granted on request · REST only, no MCP tool

Your account's latest 50 USDC withdrawals, newest first, including any made in our app. Each has the fields of a withdrawal in [Withdraw](/partner-api/endpoints/create-withdrawal).

## Response

<ResponseField name="withdrawals" type="object[]">Newest first, at most 50.</ResponseField>

<RequestExample>
```bash cURL
curl https://catchbackcards.com/api/partner/v1/withdrawals \
  -H "Authorization: Bearer $CATCHBACK_KEY"
```
</RequestExample>
