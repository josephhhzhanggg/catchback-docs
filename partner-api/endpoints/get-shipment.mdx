---
title: "Get a shipment"
api: "GET /api/partner/v1/shipments/{id}"
description: "One shipment by its id: status, tracking, the cards in it and the address it ships to."
---

Scope: `ship:cards`, granted on request · MCP tool: `get_shipment`, which takes the id as `shipment_id`

One shipment on your account, with the same fields as in [List shipments](/partner-api/endpoints/list-shipments) plus the cards and the address. It always has the current status, so it's the place to check after a [`shipment.updated`](/partner-api/webhook-events#shipment-updated) event or a `SHIPMENT_OUTCOME_UNKNOWN`.

<ParamField path="id" type="string" required>
  The `id` that [Create a shipment](/partner-api/endpoints/create-shipment) returned, or the `shipment_id` in an error. A UUID.
</ParamField>

## Response

Every field of a shipment in [List shipments](/partner-api/endpoints/list-shipments), plus:

<ResponseField name="items" type="object[]">
  The cards in the shipment. Empty until the order exists.
  <Expandable title="item">
    <ResponseField name="card_id" type="string" />
    <ResponseField name="name" type="string | null" />
    <ResponseField name="grade" type="number | null" />
    <ResponseField name="grading_company" type="string | null" />
    <ResponseField name="value" type="number | null">The card's market value in USD when you created the shipment.</ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="address" type="object | null">
  Where it ships to. `null` until the order exists, and after we've removed it, when `address_removed` is also `true`: [how long we keep it](/partner-api/shipping#customer-addresses).
  <Expandable title="address">
    <ResponseField name="name" type="string | null" />
    <ResponseField name="address1" type="string" />
    <ResponseField name="address2" type="string | null" />
    <ResponseField name="city" type="string" />
    <ResponseField name="state" type="string | null" />
    <ResponseField name="zip" type="string | null" />
    <ResponseField name="country" type="string" />
    <ResponseField name="phone" type="string | null" />
  </Expandable>
</ResponseField>

## Errors

| Status | Code | When |
|---|---|---|
| `403` | | The key lacks `ship:cards` or isn't linked to an account, the account is deleted (`"Partner account unavailable"`), or it can't request shipping |
| `403` | `FEATURE_RESTRICTED` | The account is restricted from the marketplace or from withdrawals, so its key can't read addresses. Contact us |
| `404` | | No shipment with this id on your account. An unknown id, a malformed one and another account's shipment all look the same |
| `500` | | We couldn't load the shipment. Retry with backoff |
| `503` | | We couldn't check the account. Try again |
