The Partner API lets companies, bots and AI agents work with CatchBack programmatically. A partner is a normal CatchBack account with an API key linked to it, so every action runs through the same code and the same rules as our own app.

## Basics

- **Base URL:** `https://catchbackcards.com`. Every endpoint that takes a key lives under `/api/partner/v1/`. [Public card metadata](/partner-api/endpoints/get-public-card) needs no key and lives under `/api/public/v1/`.
- **Auth:** every request to those `/api/partner/v1/` endpoints sends your key as a bearer token. See [Authentication](/partner-api/authentication).
- **Format:** JSON in and out, UTF-8. Money is in **US dollars** as numbers (not cents). Your Wallet Balance is also in dollars.
- **Where you call from:** a key doesn't get around our sanctions list. See [Where you can call from](/partner-api/errors-and-limits#where-you-can-call-from).
- **Versioning:** breaking changes ship under a new version prefix. A `v1` response may gain new fields at any time, so build your parser to ignore fields it doesn't know. What changed and when: [Changelog](/partner-api/changelog).

## How a partner account works

1. **You get an account and a key.** We create your API key with the scopes you need and link it to your CatchBack account.
2. **You fund it.** You pre-fund the account's Wallet Balance (we credit it when your wire lands). Purchases spend only that balance, at the same list price as everyone else.
3. **Cards land in your vault.** Every card you pull or buy is held by CatchBack in your account. From there you can keep it, [sell it back](/partner-api/endpoints/sell-back) at our guaranteed rates, or [list it](/partner-api/endpoints/list-card) on the marketplace.
4. **It stays off our main public surfaces.** A partner account stays off the VIP and Top Gifters leaderboards, earns no CatchPoints, and its pulls stay out of our recent-pull feeds and aren't posted to chat automatically.

The whole flow, step by step: [How it works](/partner-api/how-it-works).

## Quick start

The three calls below show the shape of the API. The [Quickstart](/partner-api/quickstart) goes the whole way, from a new key to selling a pull back. The third call spends your real Wallet Balance: to try packs on a test balance first, see [Testing](/partner-api/testing).

<Steps>
  <Step title="See what you can buy">
    ```bash
    curl "https://catchbackcards.com/api/partner/v1/catalog/packs?category=pokemon" \
      -H "Authorization: Bearer $CATCHBACK_KEY"
    ```
  </Step>
  <Step title="Look inside a pack">
    ```bash
    curl "https://catchbackcards.com/api/partner/v1/catalog/packs/pool?pack_type=bronze&category=pokemon" \
      -H "Authorization: Bearer $CATCHBACK_KEY"
    ```
  </Step>
  <Step title="Open one">
    ```bash
    curl -X POST https://catchbackcards.com/api/partner/v1/packs/purchase \
      -H "Authorization: Bearer $CATCHBACK_KEY" \
      -H "Idempotency-Key: order-0001" \
      -H "Content-Type: application/json" \
      -d '{ "pack_type": "bronze", "category": "pokemon", "quantity": 1 }'
    ```
  </Step>
</Steps>
