---
title: "List a wallet's tokens"
api: "GET /api/partner/v2/wallets/{address}/tokens"
description: "The live tokens of your program that a wallet holds, newest first, each with what a sell-back would pay right now."
---

Scope: `nft:orders`

The live tokens of your program that a wallet holds, newest first, each with what a sell-back would pay right now.

- Ownership comes from our chain watcher, so a transfer shows up within a few minutes. A quote always re-reads the owner on chain.
- At most 200 tokens are returned; `truncated: true` means there are more.

<ParamField path="address" type="string" required>
  A wallet address on your mint chain. An EVM address may be any case, but a mixed-case one must carry a valid EIP-55 checksum.
</ParamField>

## Response

<ResponseField name="holder" type="string">The address, normalized (EVM lowercase).</ResponseField>
<ResponseField name="tokens" type="object[]">
  <Expandable title="token">
    <ResponseField name="chain" type="string" />
    <ResponseField name="contract" type="string">EVM. On a Solana program, `collection` and `asset` instead.</ResponseField>
    <ResponseField name="token_id" type="string">Decimal. Keep it as a string or bigint.</ResponseField>
    <ResponseField name="status" type="string">The mint status; a token that is not yet `confirmed` can't be quoted.</ResponseField>
    <ResponseField name="card" type="object">`id`, `category` and `name` of the item.</ResponseField>
    <ResponseField name="minted_at" type="string" />
    <ResponseField name="sellback" type="object">
      Indicative; only a [quote](/partner-api/v2/endpoints/create-sellback-quote) fixes the amount. `amount`, `rate`, `fresh` (true inside the fresh window) and `locked_until` (when the value lock ends). See [Sell-back](/partner-api/v2/sell-back#what-a-sell-back-pays).
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="truncated" type="boolean">True when the wallet holds more than the 200 tokens returned.</ResponseField>

## Errors

| Status | Code | When |
|---|---|---|
| `400` | `BAD_ADDRESS` | `{address}` is not an address on your mint chain |
| `400` | `CRYPTO_WALLET_MODEL_ONLY` | Your program is on the Non-crypto model: it has no tokens or wallets. Use the [customer endpoints](/partner-api/v2/settlement) |

<RequestExample>
```bash cURL
curl https://sandbox.catchbackcards.com/api/partner/v2/wallets/0x8f3c...e21a/tokens \
  -H "Authorization: Bearer $CATCHBACK_KEY"
```
</RequestExample>
