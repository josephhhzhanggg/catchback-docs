---
title: "Verify an order's pull"
api: "GET /api/partner/v2/orders/{id}/verification"
description: "The order's provably-fair proof, and a public URL your customer can open to re-run the check."
---

Scope: `nft:orders`

Every pack is opened provably fairly. This returns the proof for an order's pull, and a public `verify_url` your customer can open to re-run the check without a key.

<ParamField path="id" type="string" required>
  A single order's `id` or `Idempotency-Key`, or one unit's `id` from a multi-pack order. A multi-pack order's own `id` or `Idempotency-Key` returns one proof per unit.
</ParamField>

## Response

<ResponseField name="verification" type="object">
  <Expandable title="verification">
    <ResponseField name="order_id" type="string">Your `Idempotency-Key`.</ResponseField>
    <ResponseField name="id" type="string">The order's id.</ResponseField>
    <ResponseField name="pull_id" type="string" />
    <ResponseField name="card_id" type="string" />
    <ResponseField name="category" type="string" />
    <ResponseField name="verified" type="boolean" />
    <ResponseField name="verification_type" type="string">e.g. `provably_fair`.</ResponseField>
    <ResponseField name="verify_url" type="string">A public URL that re-runs the check, with no key.</ResponseField>
    <ResponseField name="proof" type="object">Exactly what `verify_url` returns: the verifier's step-by-step replay.</ResponseField>
  </Expandable>
</ResponseField>

### Multi-pack orders

A multi-pack order's own `id` or `Idempotency-Key` returns `{ order_id, batch_id, verified, units: [...] }`: one proof per unit, each with its `unit` number. A unit not yet opened has `"verified": null, "pending": true`, and the order's `verified` is true only when every unit's is.

## Errors

| Status | Code | When |
|---|---|---|
| `404` | `UNKNOWN_ORDER` | No such order in your program |
| `409` | `NOT_PULLED` | The order's pack hasn't been opened yet; the body has the order's `status` |
| `503` | `VERIFY_UNAVAILABLE` | The proof couldn't be loaded right now; retry shortly |
