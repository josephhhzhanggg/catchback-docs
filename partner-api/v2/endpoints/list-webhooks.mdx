---
title: "Get your webhook"
api: "GET /api/partner/v2/webhooks"
description: "This key's webhook, as a list of at most one. The secret is never returned."
---

Scope: `nft:orders`

Returns `{ "webhooks": [ { ...webhook } ] }`, or an empty list when none is set. The secret is never returned again.

## Response

<ResponseField name="webhooks" type="object[]">
  At most one: `id`, `url`, `enabled`, `created_at` and `updated_at`.
</ResponseField>

## Errors

| Status | Code | When |
|---|---|---|
| `503` | `WEBHOOKS_UNAVAILABLE` | Webhooks aren't available on this server yet |

<RequestExample>
```bash cURL
curl https://catchbackcards.com/api/partner/v2/webhooks \
  -H "Authorization: Bearer $CATCHBACK_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "webhooks": [
    {
      "id": "c2f0e8b4-1a7d-4c39-9e55-0b6d3a8f2e17",

      "enabled": true,
      "created_at": "2026-11-17T10:00:00.000Z",
      "updated_at": "2026-11-17T10:00:00.000Z"
    }

```
</ResponseExample>
