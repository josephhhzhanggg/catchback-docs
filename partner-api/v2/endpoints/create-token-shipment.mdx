---
title: "Create a one-token shipment"
api: "POST /api/partner/v2/tokens/{tokenId}/shipment"
description: "Create and pay for a shipment of one token, with the token in the path."
---

Scope: `nft:orders`

The same as [Create a shipment](/partner-api/v2/endpoints/create-shipment), for one token: it takes the same body without `token_ids` and answers with the shipment as `quote` (no `shipment_id`, no `tokens`: the token's own `quote_id` names the shipment). Once paid, [Get a shipment](/partner-api/v2/endpoints/get-shipment) with the `quote_id` returns what the holder burns with; the burn ships the item.

<Warning>
  Always send an `Idempotency-Key`, and reuse it when retrying. See [Idempotency](/partner-api/v2/idempotency).
</Warning>

<ParamField path="tokenId" type="string" required>
  The token's decimal `token_id`.
</ParamField>
<ParamField header="Idempotency-Key" type="string" required>
  8-128 characters of `A-Za-z0-9_-`. Shared key space with [Create a shipment](/partner-api/v2/endpoints/create-shipment).
</ParamField>
<ParamField body="holder" type="string" required>
  The wallet that holds the token now. Checked on chain.
</ParamField>
<ParamField body="address" type="object" required>
  As for [Estimate a shipment](/partner-api/v2/endpoints/estimate-shipment).
</ParamField>
<ParamField body="rate" type="object" required>
  `{ "carrier": "...", "token": "..." }` from an estimate's `rates`.
</ParamField>
<ParamField body="max_cost" type="number" required>
  The most the holder will pay for shipping, in dollars: pass the estimate's `total`.
</ParamField>
<ParamField body="cover_amount" type="number | null">
  Shipping insurance cover in dollars.
</ParamField>

## Response

**201** (200 with `"idempotent_replay": true` on a replay).

<ResponseField name="quote" type="object">
  The shipment: `quote_id`, `status`, `shipping_cost`, `holder`, `expires_at`, `paid_at` and `burn` (null until paid).
</ResponseField>
<ResponseField name="payment" type="object | null">
  As for [Create a shipment](/partner-api/v2/endpoints/create-shipment): `null` once paid.
</ResponseField>
<ResponseField name="idempotent_replay" type="boolean">Present and `true` on a replay.</ResponseField>

## Errors

The same as [Create a shipment](/partner-api/v2/endpoints/create-shipment), except `BAD_TOKEN_IDS`, which doesn't apply. `TOKEN_IN_SHIPMENT` carries that shipment's `quote_id`.

<RequestExample>
```bash cURL
curl -X POST https://catchbackcards.com/api/partner/v2/tokens/81264573985362058461377125337283195667/shipment \
  -H "Authorization: Bearer $CATCHBACK_KEY" \
  -H "Idempotency-Key: okx-ship-7a20b1" \
  -H "Content-Type: application/json" \
  -d '{
    "holder": "0x8f3c...e21a",
    "address": { "name": "Alice Tester", "address1": "1 Market St", "city": "San Francisco", "state": "CA", "zip": "94105", "country": "US", "phone": "4155550100" },
    "rate": { "carrier": "USPS", "token": "usps_priority" },
    "max_cost": 9.85
  }'
```
</RequestExample>
