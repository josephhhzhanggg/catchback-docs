title: "Get a pack's odds and pool"

Scope: `nft:orders`

What one pack can pull at one [odds choice](/partner-api/v2/odds): the value bands with their chances, whether those odds are selling right now, and every item a pull can produce. This is the same information as the odds panel in our app, so show it to your customers before they buy.

The pool is live stock. Each item in it is one physical item, so an item that is pulled leaves the pool, though other copies of the same card can stay in it. Both catalog reads (List packs and Get a pack's odds and pool) can be up to a minute old: we cache them for a minute, so repeat reads are fast however often you call them (the first read after a quiet spell or a deploy can take several seconds). Stock is checked again when you create the order, so a pack that sold out in that minute is refused there: `409 ODDS_UNAVAILABLE` (with `odds`) on a pack that sells the odds choice, `409 PACK_UNAVAILABLE` (with its `reason`) on one that sells only its own odds.

<ParamField query="pack_type" type="string" required>
  A `pack_type` from [List packs](/partner-api/v2/endpoints/list-packs).
</ParamField>
<ParamField query="category" type="string" default="pokemon">
  As for [List packs](/partner-api/v2/endpoints/list-packs).
</ParamField>
<ParamField query="odds" type="string">
  `standard`, `hot`, `chill` or `classic`: one the pack sells. Default: the pack's `default_odds`.
</ParamField>

## Response

<ResponseField name="pack_type" type="string" />
<ResponseField name="name" type="string" />
<ResponseField name="category" type="string" />
<ResponseField name="price" type="number">What the customer pays, in dollars.</ResponseField>
<ResponseField name="odds" type="string">The odds choice this response describes.</ResponseField>
<ResponseField name="label" type="string">Its display label, e.g. `Hot`.</ResponseField>
<ResponseField name="tagline" type="string">A short description, e.g. `Fewer hits, bigger chase`.</ResponseField>
<ResponseField name="available" type="boolean">Whether these odds are selling right now.</ResponseField>
<ResponseField name="fresh_buyback_rate" type="number">The sell-back rate in the fresh window, as a fraction (`1` = 100%). See [Sell-back](/partner-api/v2/sell-back#what-a-sell-back-pays).</ResponseField>
<ResponseField name="consolation_probability" type="number | null">The chance of the pack's consolation prize, where it has one, else null.</ResponseField>
<ResponseField name="bands" type="object[]">
  `band` (its key, e.g. `7.5-15`), `min_value`, `max_value`, `odds` (the chance, 0 to 1, of a pull landing in that band at these odds) and `cards` (how many items sit in it). A band at 0 can't pull at these odds.
</ResponseField>
<ResponseField name="odds_choices" type="object[]">
  Every odds choice the pack sells: `odds`, `label` and `available`.
</ResponseField>
<ResponseField name="total_cards" type="integer" />
<ResponseField name="cards" type="object[]">
  Every item a pull can produce at these odds, highest value first, each with the `band` it sits in. Each item carries its catalog fields (name, set, year, grade, cert, images, `market_value`, `market_value_last_updated`, and `price`, its listed price in our shop, which sell-backs don't use).
</ResponseField>

### Packs that sell only their own odds

A pack that sells only its own odds answers `odds: "classic"` with its own band shape:

- `bands[]` with `bucket_id`, `label`, `min_value`, `max_value`, `odds`, `is_consolation` and `hittable_cards`;
- `cards[]` with `bucket_id`;
- `chase`: `{ card, probability, odds_label, label, ends_at }` when a chase item is on offer, else null;
- `odds_choices: [{ "odds": "classic", "label": "Classic", "available": true }]`, the same shape as every other pack.

## Errors

| Status | Code | When |
|---|---|---|
| `400` | `BAD_PACK` | `pack_type` missing |
| `400` | `BAD_CATEGORY` | Unknown `category` |
| `400` | `BAD_ODDS` | `odds` isn't `standard`, `hot`, `chill` or `classic`, or the pack doesn't sell it; in the second case `odds` lists the choices it sells |
| `404` | `PACK_NOT_OFFERED` | That pack isn't sold through your program |
| `409` | `ODDS_UNAVAILABLE` | Those odds aren't selling right now |
